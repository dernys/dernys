# 🧱 How I Engineer Software

```text
                    ┌─────────────────┐
                    │   Presentation  │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │   Application   │
                    │ CQRS / UseCases │
                    └────────┬────────┘
                             │
                    ┌────────▼────────┐
                    │     Domain      │
                    │ DDD / Business  │
                    └────────┬────────┘
                             │
              ┌──────────────▼──────────────┐
```
